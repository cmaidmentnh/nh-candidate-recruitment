{# ---- How to get one ---- #}
Getting a token that lasts
  1. Open developers.facebook.com/tools/explorer, pick your app, User Token, add ads_read, click Generate Access Token.
  2. Click the i next to the token → Open in Access Token Tool → Extend Access Token. That turns a one-hour token into a 60-day one.
  3. Copy the extended token and paste it above. The expiry shows once it is saved; paste a fresh one before it runs out.
  4. For a token that never expires, an admin of the Business portfolio makes a System user and generates one there. Put that in the server's META_ADS_TOKEN and it takes over automatically.
