Connect an ad account

Two ways in. Use the key on the server first. Paste a token only when that key cannot see the account.

1. Shared key {{ 'Ready' if has_server_key else 'Not set' }}

One access token serves every ad account it can reach. It is read at runtime from META_ADS_TOKEN in the environment, or from the CRM's .env next door{% if can_edit_settings %}, or failing those from the Meta settings page{% endif %}. Nothing secret is written to this app's config. {% if has_server_key %}It is set and looks valid on this environment (reading {{ server_key_source }}).{% else %}It is not usable on this environment yet.{% endif %}

It must be an access token, which starts with EAA. An App ID, App Secret or client token will be rejected. Create one under Business settings → Users → System users → Generate new token with ads_read, and assign the ad account to that system user.
  1. Click Add account at the top of this page.
  2. Leave Use the key on the server ticked.
  3. Click Find my ad accounts. The list shows every account the key can read; pick one and the name and id fill in.
  4. Say who it is for, then click Test and save. The first sync starts at once.
{% if not has_server_key %}
{{ server_key_problem }} This route stays off until a real access token is set. {% if can_edit_settings %}Paste one now, or use{% else %}Use{% endif %} route 2, which works right now.
{% endif %}
2. Paste a token for one account

For an account the server key cannot reach. About ten minutes in Meta Business Manager, once per account.

  1. In business.facebook.com/settings, open Users → System users and add one with the Employee role.
  2. Select it, click Add assets → Ad accounts, pick the account, and turn on View performance. Read access is enough.
  3. Click Generate new token, pick your app, set it to never expire, and tick ads_read and read_insights.
  4. Click Add account, untick the server key, then paste the name, the id (act_1234567890), and the token.
{% if encryption_problem %}
{{ encryption_problem }} Generate one with openssl rand -hex 32.
{% endif %}

Pasted tokens are tested first, then encrypted with AES-256-GCM. They are never shown again. Active accounts sync every hour and pull the last 30 days of account and campaign results from Graph API {{ graph_version }}. Use Sync after a big change.
